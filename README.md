An advanced remote sensing pipeline and machine learning framework designed to model, map, and analyze wildfire fuel loads and dynamic risk profiles. Focusing on the complex, highly flammable landscapes of the **Blue Mountains, New South Wales, Australia**, this repository acts as both an operational dashboard.

---

## 📄 Project Context & System Parameters

* **Study Area:** Blue Mountains, New South Wales, Australia  
* **Coordinate Reference System (CRS):** EPSG:4326 (WGS 84)  
* **Temporal Window:** September 1, 2025 – November 30, 2025 (Critical lead-up phase to the high-risk austral fire season)  
* **Core Objective:** Transitioning from baseline rule-based heuristic mapping to an empirically validated, multi-modal machine learning framework integrating optical, SAR, terrain, and micro-climate covariates.
