# Blue Mountains Bushfire Predictions

Predicting bushfire risk in the Blue Mountains, Australia using satellite imagery and machine learning.

## Overview

This project leverages remote sensing data and machine learning models to predict bushfire risk in the Blue Mountains region of Australia. By analyzing historical fire patterns, vegetation indices, weather data, and topographic features, the model identifies areas at elevated risk.

## Features

- Satellite imagery analysis (Landsat / Sentinel)
- Machine learning risk prediction models
- Geospatial data visualization
- Historical fire pattern analysis

## Tech Stack

- Python
- Google Earth Engine
- Scikit-learn / TensorFlow
- QGIS
- Pandas, NumPy, Rasterio
